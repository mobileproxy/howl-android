Защита профиля, диагностика и описание Kill Switch уже объединены; продуктовый код относительно прошедшего 58 тестов общего кандидата не менялся. Поднят VERSION_NAME с 1.0.0 до 1.0.1; база VERSION_CODE осталась 700, номер сборки добавляет существующий CI.

## Проверки

[Release CI 38807472419](https://github.com/mobileproxy/howl-android/actions/runs/38807472419), run number 118. Существующий pipeline пересобирает то же ядро `v1.14.0-lx.29` со всеми его подмодулями, выполняет debug unit-тесты и собирает minified/signed `otherRelease`. Секреты ключа выпуска используются только штатным CI, их значения в документацию не копируются.

Добавлен gate `tools/verify-release-apk.py`: apksigner проверяет новый и прежний опубликованный APK, SHA-256 прежнего файла закреплён, сертификаты должны совпасть, applicationId должен остаться `how.vpn.howl`, versionCode должен превысить текущий публичный, versionName должен соответствовать version.properties, debuggable запрещён. Метаданные, размеры, SHA-256 и SHA-256 сертификата сохраняются в `release-verification.json`. Проверка 22 строк на шести языках включена в release CI.

Локальные тесты публикации/очистки с подменённым API прошли; после добавления защиты latest их **13**. Синтаксис скриптов выкладки/отката проверен. Автопубликация сравнивает исходники выбранной сборки с уже опубликованными обычными релизами: старый или разошедшийся исходный код не заменяет latest, ошибка API останавливает публикацию; проверка повторяется перед повышением релиза. Это сохраняет ручной выпуск при повторном запуске старого workflow публикации.

Release CI **успешен**: 58 тестов, 0 провалов/пропусков, 100% successful по HTML-отчёту; сборка подписанного/minified APK прошла. Проверены строки шести языков, apksigner и отсутствие debuggable. Версия **1.0.1 (818)**, размер **34051035** байт, SHA-256 **19a9e2278cad6519a31236a6e8ef5edd3d783e14865912e2a6422db32f616cbd**. SHA-256 сертификата нового и прежнего APK совпал: `8627a0876f3baf1dcf3bf7de297398fa65bc6256a8c6ef30132483995730faa7`. Скачанный Actions APK совпал с CI-отчётом по размеру и SHA-256; ZIP CRC и наличие arm64-библиотек, включая libbox.so, проверены. Просмотрены три синтетических скриншота меню RU/DE из CI; номера версий/состояния там тестовые, это не снимки установленной 818.

## Ограничения и приёмка

Установка поверх прежней версии, миграция на Android, реальные запуск/откат ядра, VPN/TUN/DNS и маршрутизация, отмена диагностических сетевых запросов, системное сохранение JSON и системные настройки блокировки на устройстве **не проверены — SKIPPED_BY_USER**. Совпадение сертификата и возрастающий versionCode — необходимые условия обновления, но не доказательство успешной установки. Успешный запуск ядра не подтверждает доступность VPN-сервера.

Публикация использует GitHub Releases и статику gethowl.app. APK и манифест заменяются через временные файлы и переименование; манифест переключается последним, прежняя пара сохраняется с rollback.sh. Откат публичных файлов прекращает предложение нового обновления, но не понижает уже установленную версию на телефоне.

Бюджет Actions $0 не увеличивается. После проверки файлов в Releases удаляются только артефакты соответствующего release-прогона, а опубликованный APK остаётся доступным без срока Actions. Установленный клиент основного компьютера не меняется.
