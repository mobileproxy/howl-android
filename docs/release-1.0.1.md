## Ограничения и приёмка

Установка поверх прежней версии, миграция на Android, реальные запуск/откат ядра, VPN/TUN/DNS и маршрутизация, отмена диагностических сетевых запросов, системное сохранение JSON и системные настройки блокировки на устройстве **не проверены — SKIPPED_BY_USER**. Совпадение сертификата и возрастающий versionCode — необходимые условия обновления, но не доказательство успешной установки. Успешный запуск ядра не подтверждает доступность VPN-сервера.

Публикация использует GitHub Releases и статику gethowl.app. APK и манифест заменяются через временные файлы и переименование; манифест переключается последним, прежняя пара сохраняется с rollback.sh. Откат публичных файлов прекращает предложение нового обновления, но не понижает уже установленную версию на телефоне.

Бюджет Actions $0 не увеличивается. После проверки файлов в Releases удаляются только артефакты соответствующего release-прогона, а опубликованный APK остаётся доступным без срока Actions. Установленный клиент основного компьютера не меняется.
