# Howl Android: кандидат единого оформления

20.10.2026. Ветка `android/international-branding`, проверяемый код `6f95620b1bbbce07fdc3b342ffe44bebec5e0e94`, основа `fa3b1913ae33667c80c9447428992b49526eca3f` из кандидата мягкого переключения. Подготовка без публикации, установки и изменения `dev`.

## Изменения

- Приветствие и инструкция добавления подписки используют название Howl во всех 9 существующих переводах: EN, RU, DE, ES, IT, FR, FA, ZH-CN, ZH-TW. Русский интерфейс сохранён. Название установленного приложения остаётся Howl.
- В minified release нормализовано имя исходного файла (`SourceFile`), сохранены номера строк для диагностики. R8 mapping перед будущим выпуском нужно хранить отдельно в защищённом хранилище.
- Для будущей сборки Go-ядра добавлен `-trimpath`. Этот кандидат использует прежний проверенный AAR `v1.14.0-lx.29`, без пересборки/миграции ядра.
- Новый gate проверяет содержимое реального APK: Windows/macOS/Linux home-пути в именах и распакованных файлах, UTF8/UTF16, все метки приложения, старое оформление в compiled resources. Единственное точное URL-исключение относится к публичной странице политики Quad9 из закреплённого ядра; произвольные URL не исключаются. Проверяются CRC, размеры и отсутствие дублирующихся/опасных имён ZIP.
- Идентификатор `how.vpn.howl`, текущая подпись, настройки/схемы хранения и функциональные ссылки не меняются. Новый production-ключ не создан. План следующего перехода — [android-signing-rotation-decision.md](android-signing-rotation-decision.md).

- Независимое ревью: замечания о разборе локализованных меток и слишком широком URL-исключении исправлены и покрыты регрессиями; открытых существенных замечаний нет.

Gate обнаружил ложное совпадение `vpn.how` в служебном `ResTable_package.name=how.vpn.howl`. Исправление допускает только это точное структурное поле, сохраняя запрет в видимых строках; новый тест воспроизвёл дефект до исправления.
