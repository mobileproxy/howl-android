## Изменения

- Первый проход всех локаций/протоколов предшествует отдельной очереди подтверждений. До **8** проверок одновременно; свободный исполнитель сразу берёт следующую локацию, не ожидая окончания всей группы.
- Первая попытка — до **5 с**, подтверждение — до **9 с**, пауза между проходами — **2 с**, общий предел — **60 с**.
- Отдельный прогресс проходов, счётчики очередей, секундные часы и время попытки. Остановка и частичный повтор сохраняют успешные результаты. По общему дедлайну оставшиеся строки получают «Не завершено».
- Незавершённый native-запрос и занятый исполнитель не считаются отсутствием ответа сервера. Зависший запрос автоматически не дублируется; реальные блокирующие Java/JNI-пробы ограничены общим пулом из 8 исполнителей между запусками. Исправлена гонка дедлайна с ожиданием отмены.

Сценарий соответствует Windows 1.0.37. 36 общих строк совпадают во всех шести языках; XML/форматы 60 строк на язык проверены. Сторож, автовыбор, маршрутизация и ядро сохранены. Подробнее: [отчёт кандидата](first-pass-location-checks-candidate.md).
