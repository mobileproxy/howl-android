# Howl Android 1.0.5

Выпущен 20.10.2026: `1.0.5 (823)`. Исходник `0c45f66e15a0f6d347d134d1920c5badcb315226`, объединённый с dev без конфликтов. [Release](https://github.com/mobileproxy/howl-android/releases/tag/ci-39460791978-1); обновление доступно на gethowl.app.

## Изменения

- Мягкое переключение вручную и сторожем: новые соединения используют выбранный сервер, существующие сохраняют прежний маршрут, пока прежний сервер доступен. Потерянное соединение с физически недоступным сервером сохранить нельзя.
- Единое оформление Howl во всех переводах и отсутствие персональных путей сборки. Русский интерфейс сохранён.
- Совместимая ротация сертификата: Android13+ использует CN=Howl без страны/организации, Android7–12L сохраняет прежний сертификат. Старый C=RU остаётся в истории подписи и совместимых блоках APK. ApplicationId how.vpn.howl, схемы Room и форматы профилей/резервов не менялись.

- [Общий кандидат](https://github.com/mobileproxy/howl-android/actions/runs/39457353385): 155 unit, 34 Python, debug и minified APK, подпись/lineage API24–36, отклонение неверного сертификата и изменённого APK.

## Границы приёмки

Реальный VPN, Room, фон и переключения на физическом ARM-устройстве не проверены. Синтетическая проверка PackageInstaller этого не подтверждает. Ядро ради эмулятора не подменялось.

Резерв раздачи и проверенный rollback.sh подготовлены до выкладки; smoke /ru/, /en/, /ru/pages.html до/после — HTTP200. Откат раздачи не откатывает уже обновлённые Android13+ устройства: для восстановления нужен совместимый исправляющий APK с той же lineage и большим versionCode.
